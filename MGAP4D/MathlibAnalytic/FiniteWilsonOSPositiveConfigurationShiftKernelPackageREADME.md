# Finite Wilson positive-configuration shift kernel package

This package constructs a shifted Wilson kernel from an explicit finite positive-half configuration equivalence, realizes it as a raw OS-carrier linear map, descends it through the OS quotient and Hilbert completion, identifies every natural-time matrix element with an iterated Wilson Boltzmann kernel, and specializes the construction to the finite even four-torus Z2 Wilson model under explicit symmetry, positivity, and contraction conditions.

The package does not identify random-scan or heat-bath Markov time with geometric Euclidean time. It does not construct a continuum Hamiltonian or claim a physical Yang-Mills mass gap.
