## Mathematical design and alternatives

Let C_H be the existing nonnegative one-slab global action budget. Define the nonnegative physical coupling beta_H(t) = t/(1+C_H)^2. The physical Wilson action, Haar measure, top eigenvector and first Gauss-law mode are unchanged.

For C >= 0, C/(1+C)^2 <= 1/4 and (16 C^2 + 2 C)/(1+C)^2 <= 16. Consequently 0 < t <= 1/16 satisfies ANZ's original C_H beta <= 1/64 hypothesis, and its normalized slope error is at most 16 t. This estimate can be squeezed to zero when t tends to zero, without fixing H.

AOA already proves the fixed-volume right limit, so repeating that result adds nothing. A fixed-positive-physical-coupling uniform estimate cannot be inferred from the available C_H-dependent bound. The selected next step is the explicit rescaling route; it gives a joint moving-volume/zero-coupling result and does not resolve fixed-coupling infinite volume or the continuum mass gap.
