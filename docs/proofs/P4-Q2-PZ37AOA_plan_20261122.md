# PZ37AOA: genuine physical first-mode right limit

## Goal and scope

For every fixed finite H, prove the right-hand limit of the original physical Wilson top/first Gauss-law overlap divided by beta is -1/4. Use nonnegative real couplings, the exact ANZ error estimate and the pinned mathlib filter API. Preserve the original action, half spatial weights, temporal crossing, Haar measure, Hilbert carrier, eigenvector and first mode.

## Design

ANZ bounds the absolute normalized slope error by K_H*beta, where K_H=16*C_H^2+2*C_H, whenever beta>0 and C_H*beta<=1/64. At fixed H the smallness condition holds eventually at zero, and K_H*beta tends to zero. Squeeze gives the error limit; the norm-sub limit criterion gives the slope limit.

The domain is NNReal with the right-neighborhood filter at zero. This uses the original beta>=0 physical domain and requires no negative-coupling extension. Two proof strategies will be submitted to the actual pinned KuuOS structured-edit candidate generator: squeeze the absolute error directly, and squeeze the norm error with an equivalent filter argument. These are authored deterministic strategies, not claims of live external model inference or independent verifier organizations.
