# Warm Lean sandbox v1

One GitHub runner restores the exact elan, mathlib and certified project caches once. The import graph is checked once. Each candidate is tested with strict Lean in a separate scratch path. Failed candidates keep their full diagnostics; a bounded source repair is allowed only when the preceding complete diagnostic matches its guard. The pinned native CodeAI patch guard is reused. The first fully green candidate stops its group; a single lazily initialized real Lean MCP client is shared across successful groups. Source bytes, standard axiom audits and the unchanged original MGAP4D tree are checked. No failed candidate triggers independent CI, and sandbox receipts authorize no canonical or memory promotion.

The initial replay pack contains exact AOW R1/R2 and AOX R1 blobs, including the real unreachable-tactic failure and its exact one-line repair. The resulting workflow duration and per-candidate timings will be compared with the previous separate runners. This is a benchmark against the certified AOV base, not a new proof or a completed performance certification. Future packs must bind the exact certified baseline and its cache, and use explicit candidate contracts. Missing caches are infrastructure HOLD, not proof failures. No paid API or model inference is called.
